Model & Persamaan yang Digunakan

Fungsi transfer plant (tetap)

G(s) = Y(s) / U(s) = 1 / (s² + 9s + 20)
y″ + 9y′ + 20y = u(t)

Plant orde-2 dengan dua kutub riil di s = −4 dan s = −5 (teredam lebih/overdamped, tanpa osilasi alami). Parameter plant tidak dapat diubah karena mengikuti fungsi transfer loop tertutup yang ditentukan.

Persamaan kendali — PID

e(t) = r − y(t)
u(t) = Kp·e + Ki·∫e dt + Kd·(−dy/dt)
u(t) clamp → [−100, 100] %

Turunan dihitung langsung dari kecepatan keadaan dy/dt (bukan estimasi beda hingga terhadap error) sehingga bebas dari lonjakan turunan (derivative kick) saat referensi berubah. Integral dibatasi (anti-windup) agar tidak menumpuk berlebih saat u jenuh.

Fungsi transfer loop tertutup — mode PID

Y(s) / R(s) = (Kp·s + Ki + Kd·s²) / (s³ + (9+Kd)·s² + (Kp+20)·s + Ki)

Diperoleh dari G(s) = 1/((s+4)(s+5)) dengan kendali PID paralel C(s) = Kp + Ki/s + Kd·s dalam umpan balik satuan (unity feedback): Y/R = C·G / (1 + C·G). Berlaku selama sinyal kendali u(t) tidak jenuh; pada mode ON/OFF hubungan ini tidak berlaku karena histeresis bersifat nonlinear.

Simulasi ini menyelesaikan model plant secara numerik (integrasi Euler, dt = 0.1 s) karena kendali ON/OFF bersifat non-linear (histeresis) dan PID disertai saturasi output — keduanya tidak dapat direpresentasikan sebagai konvolusi Laplace linear murni. Untuk analisis kestabilan linear klasik pada mode PID tanpa saturasi, fungsi transfer loop tertutup di atas tetap berlaku.
